## 1. 体目录（目标 1）

`ArrowBodyPossibleShape` 只建**体首原子**（`BinaryOperatorPossibleShape.Operand` 一个物化入口：标识符 /
数字 / bigint / 关键字字面量），建完**不再封口**：`ArrowPossibleShape.KeepBodyOpen` 判「体到此为止」还是
「继续长」。

- **到此为止**（EOF / `;` / `,` / `)` / `]` / `}` / 换行 ASI）⇒ 当场 `TryToClose` + `Quit`，与旧行为同树；
- **继续长**（`+` `*` `?` `=` `=>` `&&` `|` …）⇒ 箭头保持 open。

`ArrowFunctionShape.CatalogGuide` 换成 `ArrowBodyPossibleShape.Catalog()`（每次返回新实例）：

| 候选 | 覆盖 | 建树 |
| --- | --- | --- |
| `ArrowBodyPossibleShape` | 体首原子 | `BinaryOperatorPossibleShape.Operand` |
| `ArrowBodyBinaryPossibleShape` | 全部二元运算符（含 `*`/`+`/`&&`/`\|\|`/`in`/`instanceof`） | 转调 `ReassociationPossibleShape.BuildByIndex`（常规长外层 + 结合更紧时拆层） |
| `ArrowBodyConditionalPossibleShape` | `? :` | 转调 `ConditionalPossibleShape.BuildByIndex` |
| `ArrowBodyAssignmentPossibleShape` | `=` | 转调 `AssignmentPossibleShape.BuildByIndex` 的 body 模式 |
| `ArrowPossibleShape` | 嵌套箭头 `a => b => …` 的内层 `=>` | 原 `BuildByIndex`（宿主换外层箭头） |

**嵌套箭头**：`IsArrowHead` 新增第二条腿 `IsArrowBodyHead`（前一个代码单元是 `EqualsGreaterThanTokenShape`）；
内层箭头建在外层 `Data` 里、成为外层的体，收口走与单层**同一判据**（`ArrowBodyEndPossibleShape`）。

**终结候选 `ArrowBodyEndPossibleShape`**：`;` / `,` / `)` / `]` / `}` 上收口——先摘尾随 trivia、
`TryToClose`、`Quit`，再把收口符按源码顺序插回父单元 `Data`（箭头之后）并驱动父目录处理那一格
（与 `Symbol.Close` 问父单元、`DeclarationAsiBoundary.ReplayLeftover` 同一手法）。`;` 因此照常落到
`VariableDeclarationListEndPossibleShape` → `CloseAtSemicolon`；嵌套箭头则逐层关掉（内层交还外层、
外层再交还声明）。

**体首不支持的形态不在增量里建**（`BodyNotIncremental`）：体首是前缀运算符 / 字符串 / 模板 / regex，
或保留字（`this` / `super` / `typeof` / `void` / `new` / `function` / `class` …）时，`=>` 格保持
`Uncertain`、整条交回 legacy 原子建树（与 B4g 的括号体同一出口）。理由：旧目录在这些形态上会抛
「没有候选形状可以构成」→ 文件级 fallback（树正确）；箭头保持 open 之后同一格不再抛，不挡就会**静默**
把后面的单元吞进箭头（错树）——这是本轮唯一一处「宁可少建，不可错树」的收窄，实测把
`a => -1` / `a => "x"` / `a => !a` / `a => this.x` 从错树拉回 ok。`{` 仍不挡（块体归语句壳，
原子建树分支不可达，保持原来的 file fallback）。

## 2. trivia：`parameter..=>` 搬进箭头 `Data`（目标 2）

`ArrowPossibleShape.BuildByIndex` 在两次 `splice` 之前用 `ItemUtil.TriviaBetween(prev, =>)` 取段、
`ItemUtil.InsertTrivia(arrow, 1, trivia)` 挂到**参数之后、`=>` 之前**（`Parent = arrow`），再从宿主
`Data` 里按身份摘掉。R4 的两个工具**一字未改**，这里只是第二个调用点。

## 3. 收口与嵌套箭头的关闭

`ArrowFunctionShape.TryToClose` 新增（legacy `FromUnits` 语义一个字没动）：

1. 先由内向外关闭**还没关的子形状**（只关形状，basic 单元不碰——它们的 `Close` 会去问父目录）；
2. 摘掉尾随 trivia；
3. `TrimEndToLastCode()`：EOF 收口时驱动层先按文件长度 `SignOut` 整棵树，箭头会被签出到尾部空白之后
   （`const f = a => a + 1\n` 的 21 而不是 20），这里收回最后一个代码子单元的终点。
