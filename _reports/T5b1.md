## 3. 改法

### 3.1 签名（26 处，逐字同形）

```text
- ## method ComputeByIndex:(units:Array<Token>, tokenIndex:int, cache:PossibleShapeCache)=>ShapeStates
+ ## method ComputeByIndex:(units:Array<Token>, tokenIndex:int, cache:PossibleShapeCache, source:PossibleSource)=>ShapeStates
```

* 26 处签名原文**完全一致**（无变体、无缺参、无 `static`/`private`），因此是一次纯文本替换后逐文件核对行数。
* 与基类 `core/syntax/possible-shape.xl.md` 的 `ComputeByIndex(..., source:PossibleSource)` / `Compute(..., source)` 现已对齐。

### 3.2 `Compute` 覆写

**本族 0 处**。`declarations/`（含 `forms/`）全目录 grep `^## method Compute:` 结果为空；基类 `Compute` 本来就把 `source` 原样转调 `ComputeByIndex`，故无需改。

### 3.3 import（20 处新增，2 处复用）

在依赖块首行加（层级按目录深度）：

| 目录 | import 路径 | 新增文件数 |
|---|---|---|
| `declarations/` | `import { PossibleSource } from "../../../core/syntax/possible-source.xl.md"` | 18 |
| `declarations/forms/` | `import { PossibleSource } from "../../../../core/syntax/possible-source.xl.md"` | 2 |

`export-inner-declaration-delegate.xl.md` 与 `import-declaration-possible-shape.xl.md` **本来就有**该 import（体内已用 `PossibleSource.Close`），未重复添加。

### 3.4 转调透传

**本族 0 处需透传**。`declarations/` 全目录 `ComputeByIndex(` 调用点只有 3 处，全在 `variable-declaration-list-possible-shape.xl.md`（N–Z 半，T5b2 的族）：`super.ComputeByIndex(units, tokenIndex, cache)` ×2（L60 / L98，仍是 3 参）、`inner.ComputeByIndex(units, tokenIndex, cache, source)` ×1（L206，已带 `source`）。
本族 26 个签名体内均**不引用** `source`（既不判来源、也不从缓存取），故形参未使用；`tsconfig.json` 未开 `noUnusedParameters` / `noUnusedLocals`，`tsc` 无告警。

### 3.5 编码

全部改动文件写入为 **UTF-8 无 BOM、LF**（与改动前一致；写盘用 `UTF8Encoding($false)`）。改后对整个 `declarations/` 递归扫描 BOM：**0 个**。
