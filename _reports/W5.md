### 2.1 为什么 F 必须用「首词闭集」而不是 `StartsNewStatementLine`

函数声明的**头部可以跨行继续**，这两条是既有用例、第一版（用 `StartsNewStatementLine` 的
「任意标识符起头」口径）把它们打成了 fallback（`FileFallbackCount 143 → 146`，`Attempts 163 → 166`）：

```ts
function f<T
extends U>(x: T): T { return x; }              // gap-sweep-newline-generic-03.ts（下一行是 extends）

declare function f(x: unknown): asserts x
is string;                                      // gap-r931-asserts-is-newline.ts（下一行是 is）
```

⇒ 闭集只放**新的声明 / 语句**首词（`declare export import function class interface type enum
namespace module global abstract async const let var using if for while do switch try throw return
break continue debugger`）。闭集之外的词一律继续等；漏收的代价是走到 EOF，
`SourceFileEndPossibleShape.BuildTrailingDeclaration` 有兜底，**不会静默丢语句**（C10）。
换成闭集后 fallback 回到 143 / 163，两条用例回到 ok。

## 5. 未完成：`ex-default-class.ts`（1 条，`s3`）

```ts
export default class A {}
export default function f() {}
export default 1
```

产物：前两条对；第三条 `export default 1` 变成 `ExpressionStatement(Identifier "default ")` +
`ExpressionStatement(NumericLiteral)`（`Identifier+1 / ExportAssignment-1 / ExpressionStatement+2`）。

**首因**：`ExportAssignmentPossibleShape.ComputeByIndex` 的 Stage 1 只认 `export` 之后的 `=`；
`default` 直接 `Stage = -1` ⇒ 整条候选 `Reject`。`export default <expr>` 今天**只**由
`SourceFileEndPossibleShape.BuildTrailingDeclaration` 的 `isExportDefault` 分支在 EOF 兜住
（所以 `export default 1` 单独成文件是 ok 的，`tmp/c-def.ts` 实测 ✅），在文件中间就没人接。

**为什么没做**：把这个分支放宽到 `default` 会同时命中 `export default class/function/interface …`，
必须再加一道「`default` 之后不是声明词」的前瞻（`SourceFileEndPossibleShape.BodyDeclarationKeyword`
是 private，要新开一个判据或公开它）。实测代价高于 1 条差异的收益，且**目标（≤75）已达成**，
所以留给下一个 WP，最小复现与判据都写在这里：

```
最小复现：  export default class A {}`n export default 1`n      （三条连排才复现）
需要改：    ExportAssignmentPossibleShape.ComputeByIndex  Stage 1 接受 `default`；
            且 `default` 之后首个代码单元不是 class/function/interface/abstract/async/namespace/module/enum/declare
            （否则 `export default class` 会被当 ExportAssignment 走 ExpressionBuilder → 显式抛错 → fallback，C10 不许）
```
