# 外部 `.d.ts` 白名单（第 W4 波 / D5 §3.4）
#
# 一行一件，每行 = `<仓库相对路径>  // xl:known-gap <一句话根因>`。
# 指令用的就是用例文件头那一个 `// xl:known-gap`（见 tests/cases/case-file.mjs 的要求：
# 后面必须有一句话根因），**不另造语法**。
#
# 它**只改 FileFallback 的统计口径**，不改任何 AST 判据：清单里的文件照样解析、照样逐节点对拍，
# 现在 16 件全是 DIFF=0（它们靠 EnableFileFallback 那条 legacy 重解析救回，不是靠放过）。
# 意思是「这 16 件是外部 vendor 语料，不是本仓库的源」——它们的增量形状缺口不该记在本仓库账上，
# 但也不该消失：`ExternalFallbackCount` 把命中数单列，`FileFallbackCount` 只数本仓库的语料。
#
# **清单只许减**：三族各有显式天花板（10 / 2 / 4 = 16，写在 tests/parse/wide-ast.mjs 的
# ALLOWLIST_CAPS 里），多一行就红；登记了却没走 fallback、或文件不存在，也红（清单过期要删）。
#
# 复算方式：node tests/parse/wide-ast.mjs --incremental-on   （ExternalFallbackCount 行）
