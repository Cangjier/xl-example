# 成员层：结论与不再试的路

**这份文件只留结论**。逐轮的现场（每一次动手、回滚、探针读数）在 **git 历史**里。

## 成员层是什么

`ClassBody` / `InterfaceBody` / `EnumBody` / `StaticBlock` 四个体**不挂语句重组队列**，
成员由**解析期单元自己成形**。它是「`class` 子树不依赖任何 reorg」清单里**最大的一处**。

## 为什么不能照 `if` / `class` 那条路走

前几族的入口都落在**一个开括号**上（`(` / `{`）：那一刻形状已经摆在桌上。
成员没有这样的字符——它以**名字**开头，而「这是个成员」这件事在读到名字时**还定不下来**
（`A` 可能是字段、也可能是方法名）。

于是形状换成：**体自己认成员边界**。体知道自己在读一张成员表（它就是那个体），
所以它可以在「第一个实义字符」上开一个成员单元，**成员的结束由成员自己判**。
这不违反「不看未来」那条铁律——判据用的全是**已经读到**的东西；而且与
`IfStatement` 判顶层逗号是同一套口径：嵌套里的 `,` / `;` 被更深一层的单元挂走了，
所以成员见到的 `,` / `;` 必定是**自己这一层**的——**不数深度**。

## 成员怎么结束

| 体 | 成员的结束符 | 备注 |
| --- | --- | --- |
| `EnumBody` | 顶层 `,` 或体的 `}` | 最后一个成员后面可以没有逗号 |
| `ClassBody` / `InterfaceBody` | 顶层 `;`、体的 `}`、或 **ASI 换行** | 方法成员还会多吃一对 `{}`（那是它自己的体单元） |
| `StaticBlock` | 就是体本身 | 静态块整体是一个成员级的构造 |

收尾一律用「**不含地退出**」：把那个字符**还给**上一级（`ReloadMessage` 走 `ReloadOwner`），
再 `TryToClose()` + `Quit()`——`IfStatement.ExitOrPre` 那一套（含「入队要倒着来」那条）。
体的 `}` 那一支问的是**祖先的 `Owns`**。

## 战略结论：**半张成员表比不搬更差**

四轮实测（第 428 / 430 / 438 / 440 轮）都撞在同一堵墙上：

| 状态 | 用例集 | 全语料 |
| --- | --- | --- |
| 完全没搬 | 1037 / 1037 | **0** 个文件 |
| 只搬字段 | 1037 / 1037 | **5** 个文件 |
| 只搬字段 + 给共用判据补「成形成员也是边界」 | 1037 / 1037 | 5 个（补丁无效，读变更差） |
| 只搬字段 + 方法（判别符 `(`） | 1017 | 133 个 |

**原因**：成员扫描跑在一张「一半成形、一半散着」的平表上**必然失准**，
而这**不是打补丁能修的**——四条补丁（`IsMemberBoundary` 加成员、`IsDeclarationBoundary` 加成员、
方法判别符改成 `(`、跨类型参数段）实测全部无效或更差。

⇒ **结论**：把成员表**一次搬完**再做，或者**先别动**。

## 落地顺序（自小而大，每步都跑全语料）

1. `EnumBody`（结束符最简单：只有 `,` 与 `}`）；
2. `StaticBlock`（体本身就是成员）；
3. `ClassBody` 的字段（`Field` 已有自己的规则与投影）；
4. `ClassBody` / `InterfaceBody` 的方法与签名（`MethodDeclaration` / `Signature` /
   `IndexSignature`）——**与第 3 步同一批做完**，别分批;
5. 取值器 / 设值器。
