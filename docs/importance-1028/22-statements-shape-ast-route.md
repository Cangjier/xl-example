### typescript/tokens/statements/statement-shape-ast.xl.md（47050B / 1038 行；StatementShapeAst）

- 结构：AST 转换层（shape→AST 的桥），不是 possible/end。唯一类 `StatementShapeAst` 全为 static：`Build(body, units, basePos, template, context)` 被语句壳的增量物化（`StatementShape.TryMountIncremental`）与收口（`BuildFromShell`）两处调用；`BuildNode` 以 `StatementOperandShape.Kind` 的整数族码分派，逐分支用 `new XxxShape(...)` 组装 AST 节点，部分分支把整段单元交回 `ExpressionBuilder`。文件不定义 basic token、不定义 possible、不覆盖 `ExitOrPre`/`ComputePossibleShapes`。
- 偏离：
  - `[S4]` ● 最终 AST 不由 `ParseFromShape(shape)` 产出：`BuildNode` 用 Kind 码判断节点种类并直接 `new` 具体节点类，节点来自「类名 + `Raw`/`Args`/`Colon`/`TailEnd` 字段拼接」，没有任何一处调用关闭后 shape 的解析入口（全仓 `ParseFromShape` 仅 `import-declaration-ast-node.xl.md:28` 一处且为未实现桩） — 证据 `statement-shape-ast.xl.md:104-110`（`if (!(node instanceof StatementOperandShape)) … const shape = node as StatementOperandShape`）、`:287-293`（`const call = new CallExpressionShape(builder.Template); call.Add(callee); … call.Add(arg)`）、`:402-406`（`const binary = new BinaryExpressionShape(...); binary.Add(left); … binary.Add(right)`）。
  - `[S3]` ● 形状树与 AST 不同构：`StatementOperandShape` 子节点数与同义 AST 节点的 children 数不一致，形状树只保留「骨架」，实参 / 操作符 token 留在字段里由收口器另加 — 证据 `statement-shape-ast.xl.md:264-267`（调用形状要求 `shape.Data.length !== 1` 即拒，只有被调用者）、`:287-292`（AST 侧 `callee` + 逐个实参）、`:378-385`（二元形状恰好两个子节点）、`:402-405`（AST 侧 `left` + 操作符 token + `right` 三个 children）、`:516-543`（可选成员形状两子，AST 侧三子含 `?.` token）。

### typescript/tokens/statements/statement-route-util.xl.md（45071B / 760 行；StatementRoute、StatementClass、StatementRouteUtil）

- 结构：工具/分派层，不是 shape、possible 或 end。两张整数码表（`StatementRoute` 11 个族码、`StatementClass` 9 个分类码）+ 一个全函数 `Decide`，被语句族各 possible、块体挂载点、bracket 角色解析共同调用，回答「这一格归哪一族 / 该建哪类壳」。无实例状态、无自己发起的 possible；`ComputeByIndex` 里没有循环。
- 偏离：
  - `[X1]` ● 用整数族码表 + `Decide`/`DecideCommon`/`DecideDeclaration`/`DecideCaseClauseHead`/`ClassOf` 的全函数分派取代 catalog guide 的逐候选收敛：谁建壳、谁 `Reject` 让位全由这套码表决定，`PossibleShapes` 的淘汰/终结语义被绕开 — 证据 `statement-route-util.xl.md:15-23`（`0 = None / 1 = ShellPlainExpression / 2 = ShellVariable / 3 = Legacy`）、`:25-47`（`None`…`ShellCaseClauseHead` 共 11 个族码）、`:49-69`（`OperandStart`…`StatementStart` 9 个分类码）、`:744-758`（`Decide` 取 `ItemStart`/`NextCode` 判族）、`:886-895`（`DecideDeclaration` 不成立再问 `IsDeclarationPending` / `DecideCommon`）。
  - `[X1]` ● 约 40 个设计外开关位与计数器作为解析行为总闸与度量（`EnableShellExpressions`、`EnableIncrementalShapes`、`EnableFileFallback`、`FileFallbackCount`、`BlockShellCount`、`LeftoverReplayCount`、`BracketRoleFallbackCount`、`StuckShellRecoveryCount`、`EofDiscardedStatementCount` …）：关掉一个开关就整段回到另一条解析路径，IMPORTANCE 未定义这种分支位与计数 — 证据 `statement-route-util.xl.md:73-93`、`:97-165`、`:167-187`、`:1031-1071`（`BracketCreatePossibleCount`、`BracketRoleReplayFailureCount`、`ExprBracketGuideCount`、`ContainerShapeBuildCount` …）。
