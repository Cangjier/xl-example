# code 族 severity title rule（文档原文） detect（怎么检查） include exclude
字段说明与规则
code
D 开头 = Debug（运行期可观察，靠插桩 + 运行证实）；Q 开头 = 质量（只能读代码判断）。D/Q + 2~4 位数字，全文件唯一。
kind
由 code 前缀决定，改 code 会自动跟着改；两者不一致时这里会报错。
severity
error（必须）/ warning（应当）/ info（建议）。
title
一句话说明这条规则是什么，会出现在报告表格里。
rule
规范文档里的原文摘录，不要改写。
detect
怎么检查它：Debug 码写运行期观察什么，质量码写读代码时看什么。
include
这条码只管这些目录（相对仓库根，逗号分隔），例如 src, packages/api。空 = 覆盖所有源文件。
exclude
这条码不管这些目录，例如 src/legacy。空 = 不排除任何目录。
作用范围
范围外的位置不算这条码的违规：审查 / 插桩 / 运行期诊断都会按范围校验，超出就被打回。
未知字段
文件里手写的其他字段会被原样保留。
include / exclude 用逗号或换行分隔；空白行会被忽略；保存时会按 code / kind / title / severity / rule / detect / include / exclude 的顺序重写，末尾补一个换行。
