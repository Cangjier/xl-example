# catalog guide 与 shape token：设计

## 1. token 的树

```
Token
 ├─ CommonToken            通用字符块（名字、数字、字面量文本）
 ├─ SymbolToken            符号块
 ├─ Bracket                配对符号
 ├─ CommentToken           注释
 ├─ WrapToken              软换行
 ├─ StringToken            完整字符串支持（由模板配置，见 §2）
 ├─ RegexToken             正则支持
 └─ LanguageToken
      ├─ LanguageCatalogGuideToken → LanguageCatalogGuideTokens
      └─ LanguageShapeToken        → LanguageShapeTokens
```

1. **`Token` 是唯一的骨架。** 子单元表、`Parent`、`MountedUnit`、挂载与卸载、搬移、开启与关闭、
   区间——全部在它上面。**不设第二层骨架**。
2. **`CommonToken` 到 `StringToken` 这几类不含任何语言词。** 它们只读**词法表**（见 §1.1），
   所以放在 core。
3. **`LanguageToken` 是每门语言一份实现的那一层。** 它承载词法表、语言词表、身份判据的实现、
   以及**装配入口**。

### 1.1 词法表

| 表 | 内容 |
| --- | --- |
| 符号 / 空白 / 数字表 | 哪些字符算符号 / 空白 / 数字 |
| 配对表 | 哪两个符号配成一对括号 |
| 运算符集 | 赋值 / 比较 / 复合赋值 / 成员 / 语句结束符 |
| 词表 | 关键字、修饰词、声明词 |
| 字符串配置 | 引号 / 转义 / 原始模式 / 插值 / 模板 / 多行 / 正则（见 §2） |

全部由**语言层**在装配时写进模板。core 只读表，**一个语言词都不许有**——
表可以有最保守的空默认值（什么都不算），但不许有一份看起来像某门语言的默认值。
模板每次解析新建一份，所以"语言层覆盖默认值"天然成立。

## 2. `StringToken`

**它提供"完整字符串支持"，不是某一门语言的字符串。** 引号、转义、插值、多行，
全部由模板配置给出；换语言换的是配置，不是类。

| 配置 | 决定什么 |
| --- | --- |
| 引号集 | 开串 / 闭串符号；是否支持成组引号 |
| 转义 | 引导符；合法序列；未知转义如何处理 |
| 原始 / 逐字模式 | 是否存在"不解释转义"的模式，及其写法 |
| 插值 | 是否存在；开 / 闭定界符；能否嵌套 |
| 模板形态 | 是否有"被调用的模板串" |
| 多行 | 是否允许跨行；跨行时空白与换行如何呈现 |

1. **一种类，不是一族类。** 形态是**状态与配置**，不是类型。
2. **配置按形态切分。** 一份配置声明若干形态（普通 / 原始 / 插值 / 模板）；
   同一时刻只处于其中一个。
3. **配置必须是数据。** 不许是函数或正则——那等于把一门语言的语法钉进 core。

### 2.1 双重身份

| 角色 | 内容 |
| --- | --- |
| 字符驱动 | 吃字符，按配置收敛到出口 |
| 树节点 | 产生产物节点、能挂子单元 |

**它不需要 catalog guide**：形态在开串那一刻由配置与开串符号**一次定死**，没有池要收敛。

**插值是唯一的接点**：空洞里的内容由**挂载的子单元**自己啃。

## 3. catalog guide

**状态**是一格可能形状池；**输入**是它自己 data 里积压的已关闭 token；**输出**是收敛成唯一形状。

| # | 契约 | 内容 |
| --- | --- | --- |
| **C1** | 挂载在树里 | 它是一个真实单元，`MountedUnit` 指在它身上，字符经它转给子单元 |
| **C2** | 池的初始值由**挂它的那个** shape 声明 | 挂载方声明"我的下面可能有哪些子形状" |
| **C3** | 只读自己那一部分 | 只有它自己的 data 与它自己的状态；不看未读到的字符 |
| **C4** | 收敛是纯的 | 不改树、不建单元、不关闭别人 |
| **C5** | 池单调不增 | 初始池取最保守的完全集合 |
| **C6** | 不进产物 | 它不产生产物节点，且这一点必须显式声明 |


### 3.1 收敛形状函数

```
converge(guide,可能形状池) -> 可能形状池
```

| 项 | 是什么 |
| --- | --- |
| 输入 | guide 自己 data 里积压的那些已关闭 token，当前可能形状池 |
| 输出 | 修改后，缩小（或不变）之后的池 |

- **关闭** 只是一个**触发信号**。
- **它不是识别器，是排除器**；识别是排除到只剩一个之后的副产品。单调性因此是构造出来的。

---

## 4. 生命周期

- create     由shape token构造时创建并自动挂载
- converge   basic token 关闭 → 触发一次收敛 ：basic token关闭时通过parent往上找到catalog guide token
- resolve    池 == 1 → 建出那个形状的 token
- exit       当所在Shape Token结束时，MoveDataTo Parent(Shape token) → RemoveSelf

---

## 5. 失败与收敛失败

三种，不许混：

| 情形 | 含义 | 行为 |
| --- | --- | --- |
| **池 = 0** | 某个事件把**最后一个**可能形状也排除了 | **设计缺陷**：收敛表那一格**划多了**。报错带证据：哪一次关闭、那个 token 是什么、清空前池里有什么 |
| **构造结束仍 > 1** | 池太宽，或缺一条判别事件 | 需要"构造结束"事件（外层 shape 关闭 / 输入结束）才能判 |
| **池 = 1 但是错的** | 收敛把事件序列接受成了错的形状 | 形式化上**不可判定**。承认它存在，只由**逐字节等价**兜底 |
